# SEOUL 2049 : 폐허의 도시 (v0.9)

이터널시티에서 영감을 받은 **포스트 아포칼립스 서울 배경의 2.5D 쿼터뷰 액션 RPG**입니다.
빌드 과정 없이 브라우저에서 `index.html`을 열기만 하면 실행됩니다.

## 실행 방법
- `index.html`을 브라우저(Chrome/Edge/Firefox)로 엽니다.
- 또는 로컬 서버: `python3 -m http.server` 후 `http://localhost:8000` 접속

## 조작법
| 키 | 기능 |
|---|---|
| WASD / 방향키 | 이동 (화면 기준 방향) |
| 마우스 | 조준 |
| 좌클릭 (누르고 있기) | 공격 / 연사 |
| R | 재장전 |
| Q | 주무기 ↔ 보조무기 교체 |
| 1 ~ 4 | 스킬 (집중 사격 · 수류탄 · 응급 처치 · 아드레날린) |
| 5 | 구급상자 사용 |
| E | NPC와 대화 |
| I / C / J | 인벤토리 / 능력치 / 임무 |
| ESC | 창 닫기 |

## 게임 특징
- **2.5D 쿼터뷰(아이소메트릭) 시점**: 층수가 다른 입체 건물과 창문 불빛, 폐차·바리케이드, 플레이어를 가리는 건물은 자동 반투명
- **160×160 타일의 폐허 도시 맵**: 도로, 폐차, 붕괴된 건물, 공원
- **5개 지역**: 시청역 생존자 캠프(안전지대) → 명동 잔해 → 종로 폐허 → 용산 군사구역 → 여의도 방사능 지대
  - 캠프에서 멀어질수록 적의 레벨이 올라가고 분위기가 어두워집니다.
  - 지역마다 랜드마크(발견 보상), 고유 위협(무리 출몰·드론 편대·방사능 웅덩이), 특산 장비가 있습니다.
- **적**: 감염자, 변이견, 약탈자(원거리), 변이 거한, 경비 드론(비행), 보스 '방사능 군주 타이탄'
- **무기 9종, 각자 다른 역할**: 사거리·넉백·경직·이동 무게가 다름 (권총 탄약 무한, 산탄총 밀쳐내기, 저격 관통·경직 등)
- **장비 2.0**: 등급(일반~전설) + 추가 옵션 14종(무기 계열 전용 4종 포함) + 전설 고유 효과 6종 + 강화 +10. 같은 무기라도 더 좋은 개체를 노리는 파밍
- **성장**: 레벨업마다 능력치 포인트 3 — 근력(근접형) · 사격(총잡이) · 체력(생존형) · 민첩(기동형). 각 능력치가 스킬 하나씩을 강화하며, 의무병에게서 능력치 초기화 가능
- **메인 퀘스트 4장**: 지역을 따라가는 이야기, 랜드마크 도착·아이템 회수·네임드 적 사냥, 무전으로 진행
- **NPC**: 암시장 상인(구매/판매), 생존자 대장(임무 6종), 의무병(무료 치료·능력치 초기화), 정비공(장비 강화 +10)
- **탄약 관리**: 총기는 예비 탄약을 소모합니다. 드랍 또는 상점에서 보충하세요.
- **자동 저장**: 브라우저 localStorage에 20초마다 저장, 이어하기 지원
- 사망 시 캠프에서 부활하며 보유 크레딧의 10%를 잃습니다.

## 파일 구조
```
index.html      화면 구성 (캔버스 + HUD/패널)
css/style.css   UI 스타일
js/util.js      유틸리티 (난수, 수학)
js/data.js      무기·방어구·적·지역·스킬·임무 데이터
js/world.js     절차적 도시 맵 생성(건물 높이 포함), 충돌, 시야 판정
js/render.js    2.5D 쿼터뷰 렌더러 (투영, 깊이 정렬, 바닥 청크 캐시, 스프라이트, 조명, 미니맵)
js/assets.js    캐릭터 그림(스프라이트) 등록 목록
tools/sprite-tool.html  Gemini 이미지 → 게임용 스프라이트 가공 도구
docs/ART_GUIDE.md       아트 제작 가이드
js/entities.js  아이템 생성, 플레이어 능력치, 적 생성
js/ui.js        HUD, 인벤토리, 상점, 대화, 미니맵
js/game.js      게임 루프, 전투, AI, 저장
js/quests.js    메인 퀘스트(챕터)·네임드 적
js/monsters.js  엘리트 접두어·네임드 패턴·세력 다툼
js/assault.js   어설트(랜드마크 거점 탈환전)
```

캐릭터·랜드마크 그림은 Gemini로 만들어 교체할 수 있습니다: `docs/ART_GUIDE.md`, 프롬프트 모음 `docs/GEMINI_PROMPTS.md` 참고 (가공 도구: `tools/sprite-tool.html`).

밸런스 수치는 대부분 `js/data.js`에서 바로 수정할 수 있습니다. 버전별 변경 내용은 `CHANGELOG.md`를 참고하세요.
