# SEOUL 2049 : 폐허의 도시 (v1.29.1)

이터널시티에서 영감을 받은 **포스트 아포칼립스 서울 배경의 2.5D 쿼터뷰 액션 RPG**입니다.
빌드 과정 없이 브라우저에서 `index.html`을 열기만 하면 실행됩니다. PC와 모바일(터치) 모두 지원합니다.

## 실행 방법
- **PC**: `index.html`을 브라우저(Chrome/Edge/Firefox)로 엽니다. 또는 `python3 -m http.server` 후 `http://localhost:8000`
- **모바일**: GitHub 저장소 **Settings → Pages**에서 Source를 *Deploy from a branch*, 게임 브랜치 `/ (root)`로 저장 →
  1~2분 뒤 `https://kimguard111-ai.github.io/NEW-GAME/` 를 가로 화면으로 열기. 브라우저 메뉴의 **홈 화면에 추가**로 앱처럼 실행
- 기기를 옮길 때: 설정(O) → **세이브 코드 만들기** → 다른 기기의 설정 → **세이브 코드 불러오기**

## 플레이 가이드
- **출격과 탈출 (v1.3)**: 시청역 캠프가 거점입니다. **작전 장교 윤씨**에게서 맵(명동 → 종로 → 용산 → 여의도 → 지하 연구소 · 강남 → 잠실, 이야기 진행으로 해금)을 골라 출격하고, 맵 끝의 **초록 ◎ 탈출 지점**에 5초 머물러 귀환합니다. 이번 출격에서 주운 장비·크레딧은 탈출해야 확정되고, 죽으면 그것만 잃습니다. 귀한 물건은 **창고 관리인 정씨**의 창고에 맡기세요.
- **적은 정해진 수만 (v1.16)**: 출격 맵의 적은 무한히 나오지 않습니다. 잡은 만큼 줄어들고(목표 창 「남은 적」), 오래 머물면 경보 단계에 따라 증원만 옵니다. 스킬은 암시장 상인 박씨의 「스킬 교범」에서 크레딧으로 배웁니다.
- **엔드게임 (v1.15)**: 어설트 위협 6~10은 매주 바뀌는 변형 규칙이 붙고, 주간 도전 3개를 모두 끝내면 전설 장비. 임무 창(J)에 도감·업적·기록 탭, 가방 정렬·장비 잠금.
- **캠프 시설 (v1.13)**: 생존자 대장 한씨 → 「캠프 시설」에서 의무실·사격장·창고 증축·작업대·무전실을 3단계까지 짓습니다. 지은 시설은 캠프에 실제로 생기고, 무전실이 있으면 출격 지도에서 맵마다 이번 사건을 미리 볼 수 있습니다.
- **세트 · 고유 장비 (v1.12)**: 지역마다 세트 장비(종로 자경단 · 용산 강철 부대 · 여의도/연구소 방사능 사냥꾼 · 강남/잠실 블랙선)가 나오고, 2·3부위를 맞추면 세트 효과. 필드 보스·키메라·타이탄·레이븐·바벨은 낮은 확률로 고유 장비(분홍)를 떨어뜨리며, 못 얻을 때마다 확률이 오릅니다. 전설 방어구·헬멧에도 전설 효과가 붙습니다.
- **특성 · 스킬 갈래 (v1.11)**: Lv5부터 5레벨마다 능력치 창(C)에서 특성 3개 중 하나를 고릅니다(의무병에게서 초기화). 스킬마다 갈래 2개 중 하나를 캠프에서 고를 수 있습니다 (집속탄·소이탄, 재생 주사·방어막 등).
- **돌발 사건 · 경보 (v1.10)**: 출격마다 보급 투하 · 부상당한 생존자 · 잠긴 금고(열쇠 소지자) · 변이 둥지 · 떠돌이 상인 중 1~2개(미니맵 노란 ◆). 주황 점선 ◎은 크레딧을 내거나 발전기를 켜야 열리는 특수 탈출. 4·7·10분마다 경보가 올라 적이 늘고, 3단계엔 추적대가 옵니다.
- **뒤지기 · 시체 가방 (v1.4)**: 맵 곳곳의 노란 반짝임(쓰레기 수거함·차 트렁크·배낭·군용 보관함)을 [E]로 뒤지세요 — 움직이면 취소. 죽으면 주운 것이 그 자리 **시체 가방**에 남아, 같은 맵에 다시 출격해 회수할 수 있습니다.
- **강남 · 잠실 (v1.6)**: 방패 돌격병은 정면 피해를 65% 막으니 구르기로 뒤를 잡거나 폭발로. 은신 변이체는 일렁이는 윤곽과 보랏빛 눈을 찾으세요. 석촌호수 물속에선 모두 느려집니다.
- **지하 연구소 (v1.5)**: 제4장을 끝내면 열리는 어두운 실내 던전(Lv18~24). 출격마다 구조가 바뀌고, 가운데 격리실의 최종 실험체 「키메라」가 영웅 이상 장비를 줍니다. 보안 포탑은 벽 뒤로, 산성 원은 굴러서 피하세요.
- **전투**: 적은 공격 전에 예고합니다 — 머리 위 붉은 **「!」**(감염자), **붉은 선**(변이견 도약·약탈자 조준), **바닥의 원**(거한·보스). 보고 **구르기**로 피하세요. 경직을 주는 무기(도끼·산탄총·저격)는 적의 공격 준비를 끊습니다.
- **근접 콤보 (v1.9)**: 계속 휘두르면 3타째에 마무리 — 쇠파이프 강타 · 도끼 회전 베기 · 블레이드 돌진 찌르기. 구르기 직후 공격하면 곧장 마무리. 기관총은 쏠수록 빨라지고, 소총은 끊어 쏘면 첫 발이 정확합니다.
- **총소리**는 근처 적을 불러 모읍니다. 근접 무기는 조용합니다. 3초 안에 이어 잡으면 **콤보** 경험치 보너스(최대 +50%).
- **이야기 6장**: 명동 → 종로 → 용산 → 여의도 → 강남 → 잠실. 레벨이 되면 무전으로 다음 장이 시작되고, 목표 방향은 화면 화살표와 미니맵에 표시됩니다.
- **지역**: 캠프에서 멀어질수록 강해집니다(명동 Lv1~4 · 종로 5~9 · 용산 10~15 · 여의도 16~20 · 연구소 18~24 · 강남 20~25 · 잠실 25~30). 지역마다 특산 장비, 여의도에는 방사능 웅덩이(방독면 헬멧 권장).
- **엘리트(◆)**: 광폭한·중장갑·폭발하는·분열하는·지휘관 — 경험치 4배, 장비 추가. **필드 보스**는 미니맵 붉은 깜빡임.
- **건물**: 🚪 간판이 있는 상가는 들어갈 수 있습니다. 안에 적과 보급 상자.
- **어설트**: 발견한 랜드마크 앞에서 [E]. 웨이브 3개 + 거점 보스, 클리어 시간으로 S/A/B. 클리어하면 **위협 1~5** 단계가 열립니다.
- **레이드**: 여의도 끝(미니맵 초록 점)의 방사능 군주 타이탄 — 3페이즈, 처치 후 4분마다 부활.
- **장비**: 등급(일반~전설) + 추가 옵션 + 전설 고유 효과. 정비공 최씨에게서 **강화(+10) · 분해 · 옵션 재조정**. ▲ = 지금 장비보다 좋음.
- **매일**: 오늘의 의뢰 3개(임무 창 J) — 끝내면 희귀·영웅 장비.
- 사망 시 캠프에서 부활하며 크레딧 10%를 잃습니다. 20초마다 자동 저장.
