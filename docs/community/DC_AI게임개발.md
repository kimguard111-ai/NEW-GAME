### 뭐 하는 게임이냐면
- **출격 → 파밍 → 탈출**: 탈출 지점에 5초 서 있어야 주운 게 확정. 죽으면 시체 가방에 남고 다음 판에 가서 되찾을 수 있음
- **맵 6개**: 명동 · 종로 · 용산 · 여의도 · 강남 · 잠실. 맵마다 적 · 필드 보스 · 돌발 사건이 다름
- **엔드게임**: 지하 연구소 B1~B5, 스카이타워 20층~옥상 도전 던전 · 신화 무기 3종
- **디아블로식 가방**: 무기마다 칸 크기가 달라서 뭘 버리고 뭘 챙길지 고민하게 해 놨음
- 동료 3명 · 스킬 5갈래 · 장비 옵션 · 강화 · 세트 · 총기 부품 · 자라는 캠프

### AI를 어떻게 썼냐면
- **코딩: Claude Code** — 나는 기획이랑 「이거 이상함, 이렇게 바꿔」 판단을 하고, 코드는 거의 다 AI가 짬. 순수 JS + 캔버스, 라이브러리 없음. 지금 코드 1만 2천 줄쯤, 패치 v0.1 → v1.93
- **그림 · 배경 음악: Gemini** — 캐릭터 · 적 · 보스 · 건물 · 아이콘 다 뽑아서 게임에 맞게 잘라 씀. 음악도 맵별로 뽑음
- **코드 점검: ChatGPT** — 다른 AI한테 코드 리뷰 맡겨서 버그 찾고 고침 (꽤 쓸만했음)
- **밸런스: 봇** — 혼자 게임을 돌리는 테스트 봇도 AI한테 짜게 해서, 맵마다 사망률 · 레벨 곡선 재고 숫자 맞춤

해보니까 AI가 코드는 빨리 짜는데, **재미 판단이랑 「뭔가 이상함」 잡는 건 결국 사람 몫**이더라. 그래서 테스트가 필요함 ㅋㅋ

### 부탁
버그 · 밸런스 · 「여기 재미없다」 뭐든 댓글로 주면 바로 고침.
**설정(톱니) → 「피드백 복사」** 누르면 기종 · 프레임 · 진행 상황이 한 번에 복사되니까 그거 붙여 넣고 한마디만 적어 주면 진짜 큰 도움 됨 (어디로 전송되는 거 아님, 복사만 됨).

- 저장은 브라우저에 됨. 다른 기기로 옮길 땐 설정 → 세이브 코드
- 한 번 켠 뒤로는 인터넷 없어도 실행됨
- 패드 꽂으면 패드로도 됨

## 댓글 답 미리 (자주 나올 것)

- **"AI가 다 만든 거면 니가 한 건 뭐냐"** → 뭘 만들지 정하고, 해보고, 이상한 거 잡아서 고치라고 시킨 거. 패치를 180번 넘게 돌렸음. 코드 타자는 AI가 쳤고 방향은 내가 잡음
- **"무슨 AI 썼냐 / 프롬프트 공유"** → 코딩 Claude Code, 그림·음악 Gemini, 리뷰 ChatGPT. 그림은 「쿼터뷰 · 픽셀 느낌 · 배경 투명」 위주로 뽑고 잘라 씀
- **"폰에서 버벅임"** → 설정 → 화면 해상도를 「보통 / 낮음」으로. 자동으로도 내려가게 해 놨음. 「피드백 복사」 붙여 주면 그 기종 맞춰서 고침
- **"한국어만?"** → 지금은 한국어만
