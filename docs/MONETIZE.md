# 수익화 준비 (광고 보기 · 결제로 외형 얻기) — v2.0.32

**지금 상태: 코드는 들어 있지만 스위치가 꺼져 있음.** 실서비스(플레이스토어 1차 출시)에서는 화면에 아무것도 안 보이고, 스토어 설문 · 개인정보처리방침의 「광고 없음 · 결제 없음」이 그대로 맞습니다.
테스트 주소(`…hangang-test…`)에서만 켜져서 흐름을 눌러 볼 수 있습니다 (가짜 광고 3초 · 가짜 결제 확인창).

## 구조 (파일 2개)
| 파일 | 역할 |
|---|---|
| `js/monetize.js` | `MONEY` 스위치 · `Monetize` 공급자 어댑터 · `Unlocks` (가졌나 · 광고 횟수 · 구매 · 물어보기) |
| `js/looks.js` | 외형 항목 정의. 팔 항목에 `ad: 횟수` · `sku: 상품ID` · `price: 표시가격` 만 적으면 됨 |

- 가졌나 = **무료 조건(레벨 · 업적)을 채웠다 OR 샀다/광고로 얻었다**. 어느 쪽이든 같은 항목이 열림
- 저장: `p.own` = 얻은 항목 · `p.adProg` = 광고 본 횟수 (세이브에 같이 저장됨, 구버전 세이브도 안전)
- 잠긴 항목을 누르면: 광고 가능 → 「광고 보기?」 → 아니오면 「구매?」 순서로 물어봄
- 업적 전용(안 팖): 비행모 · 베레모 · 순백 궤적 — 가장 어려운 조건은 자랑거리로 남김

## 켜기 전에 꼭 할 일 (순서대로)
1. **실제 공급자 붙이기** — `Monetize.rewardedAd()` · `purchase()` · `restore()` 의 `TODO` 두 곳만 채우면 됨
   - 결제: 구글 플레이 결제 (TWA 는 Digital Goods API + Payment Request) → Play Console 에 「일회성 상품」 `head_…` · `trace_…` 등록 (상품 ID = `sku`)
   - 광고: 구글 H5 게임 광고(웹 · 보상형, 별도 승인 필요) 또는 앱 광고 SDK (Capacitor 전환 필요). 반드시 **끝까지 봤을 때만** `true`
2. **개인정보처리방침 · 이용약관 수정** — 광고 SDK 가 수집하는 정보 (광고 ID 등) · 결제 · 환불 규정 · 광고 노출 안내
3. **Play Console 설문 다시 답하기** — 「광고 포함: 예」 · 「앱 내 구매: 있음」 · 데이터 보안 양식에 광고 ID · 구매 내역 추가 · 콘텐츠 등급 다시
4. **동의 화면** — 광고 맞춤 동의(필요한 지역) · 어린이 대상 아님 유지
5. **환불 · 복원** — 기기를 바꾸거나 데이터를 지웠을 때 `restore()` 로 산 것 되살리기 (설정 → 「구매 복원」 버튼 추가 필요)
6. `MONEY` 의 `ads` / `iap` / `provider` 를 켜고 테스트 주소에서 실제 테스트 결제 → 프로덕션

## 알아둘 점
- **세이브를 직접 고치면 `p.own` 을 만들 수 있음** (브라우저 게임의 한계). 꾸미기뿐이라 영향이 작아서 받아들이되, 나중에 서버 영수증 확인이 필요하면 `Unlocks.grant` 한 곳만 막으면 됨
- 성능(전투력)에 영향을 주는 것은 팔지 않는 방침 유지 — 장비 · 경험치 가속 판매는 「소중한 장비」 방향과 충돌
- 광고는 **선택형(눌러야만)** 만. 강제 광고 · 화면 가림 광고는 넣지 않음
- 1차 출시 후 반응을 보고 2차 업데이트로 켜는 것을 추천 (심사 위험 · 출시 속도)
