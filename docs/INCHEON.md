# 파트 2 「인천 편」 설계서 (v3.0 · 개발용 · 출시 후 공개)

**한 줄**: 서울 편 끝(7장)에서 펌프장 통신기에 잡힌 「서쪽 — 바다 쪽」 신호를 따라 **한강을 건너 인천으로**. 레벨 **40 → 60**, 일반 지역 4곳 + **도전 던전 1곳(인천공항)**, 이야기 5장(8~12장), 마지막은 **인천항 부두에서 배가 떠나는 방어전**.

- 개발은 **테스트 브랜치에서만**, 매일 조금씩. 공개는 스토어 출시(1차) 뒤 첫 대형 업데이트 때 (`V3_READY = true` 한 줄)
- 스위치가 꺼진 동안 프로덕션 화면 · 세이브 · 밸런스는 **하나도 안 바뀜** (v2.0 한강과 같은 방식: `V3_READY` → `V3_OPEN`, 주소 끝 `?v3` 로 미리 열기)

### 도전 던전: 인천공항 (엔드게임 · `airport` · 연구소 · 스카이타워와 같은 5층 구조)
이야기(8~12장)를 끝낸 뒤 출격 지도 **엔드게임 줄**에 열림. 층마다 강해지고, 하드 모드 · 비상 계단 탈출은 기존 던전 규칙 그대로. 레벨은 Lv56에서 시작해 층마다 +1~2 (B5 ≈ Lv62~64 · 만렙(60) 기준 도전 · 최종 장비 사냥터).
| 층 | 구역 | 분위기 · 특징 |
|---|---|---|
| B1 | 입국장 · 수하물 | 컨베이어 · 버려진 캐리어 · 넓은 홀 |
| B2 | 보안 검색 · 세관 | 좁은 통로 · 검색대 바리케이드 · 엄폐물 많음 |
| B3 | 화물 터미널 | 컨테이너 선반 · 지게차 · 직선 통로 |
| B4 | 항공기 격납고 | 기체 아래 전투 · 정비 로봇 |
| B5 | 관제탑 | **도전 보스 「관제 AI」** (관제 드론을 부르는 중앙 컴퓨터 + 변이체) |
- 기존 연구소(`lab`) · 스카이타워(`tower`) 코드(`DUNGEONS` · 층 생성 · 출구)를 그대로 재사용 → 지역 맵보다 코드 작업이 작고, **그림(층 바닥 · 벽 · 소품 9종 · 보스)이 대부분**
- 보스 고유 장비 · 신화급 보상: 도전 던전 전용 최상위 장비 (**외골격 Lv60 단계 + 신화급**) — 6단계(레벨 60 · 장비)에서 설계
- 출입 위치는 연구소처럼 **출격 지도의 한 칸**(「인천공항 · 도전」) — 맵 안에 입구 소품을 두지 않음

- 한강 다리(Lv30~34)에서 **서쪽 출구**가 열리면 남동공단으로. 출격 지도에서 「인천 편」 줄이 새로 생김 (엔드게임 줄 위)
- 크기: 한강(140)과 비슷하거나 작게 (**차이나타운은 작고 촘촘하게 ~80** · 나머지 96~130) · 도로 격자는 기존 도시 생성기를 그대로 쓰고, 지역 특색은 소품 장면(`SCENES`)과 질감으로 (v2.0.10 방식)
- **송도는 「도시」가 아니라 아울렛 단지 하나가 맵 전체**: 가운데 광장(시계탑) + 바둑판 쇼핑 거리 + 가장자리 대형 주차장. 가게마다 들어갈 수 있는 상점(`shop`)을 많이 두어 **파밍 맛**이 큰 지역으로 (매장 안 보급 상자 · 마네킹 · 지하 연구 입구)
- **남동공단 · 소래포구는 두 얼굴**: 안쪽 공단 = 큰 건물 사이 직선 도로 · 오염 웅덩이(독가스 — 기존 시스템 재활용 · 피하거나 마스크 · 방호복) / 바깥 포구 = 낮은 어시장 건물 · 염전 격자 · 갯벌(속도 감소 지대 후보) · 소래철교(긴 다리 엄폐물). 공단→포구로 갈수록 분위기가 바뀌는 **띠 구성**
- **차이나타운은 좁은 골목 + 한가운데 패루**: 시야가 막히는 근접 전투 지형 (용산 · 종로보다 더 촘촘하게). 중화요리집 · 한약방 · 잡화점이 상점, 생존자 공동체는 NPC (장 8~9의 거점)
- **상표 원칙**: 송도 아울렛은 실제 상호 · 로고 · 간판 글자를 쓰지 않고 「일반적인 프리미엄 아울렛 단지」의 분위기(파스텔 유럽풍 건물 · 시계탑)만 그림. 차이나타운도 한자 · 글자 없는 빈 간판 (간판 글씨는 게임이 씀)

## 4. 레벨 · 성장 (⚠ 가장 신중해야 할 부분)
`MAX_LEVEL` 40 → **60** 은 **스위치가 켜질 때만**. 건드릴 곳:
- 경험치 곡선 `expNext` (**41~60 구간 · 20레벨** · 한 레벨에 ~25~40분 목표 → 인천 편 전체 8~14시간). 지역 레벨대가 겹치지 않게 4~5레벨씩 넓게 배분
- 특성 `PERK_TIERS` 에 **Lv45 · Lv50 · Lv55 · Lv60** 단계 추가, 스킬 포인트 · 능력치 포인트 보상 (스킬 등급 5 이후 확장도 검토)
- 장비 단계: 블랙선 전투복(Lv40) · 처리반 강화복(Lv50) · **외골격(Lv60, 최종 장비)** 과 각 헬멧이 **이미 정의됨** (몸 그림 재사용 · 색만 다름 — v2.0 에서 10레벨마다 한 단계로 미리 깔아 둠). 무기는 Lv40~60 단계를 추가 (희귀도 곡선 유지, `ECON.gear 0.22` 기준)
- 던전(연구소 · 스카이타워 · 하드): 인천 편이 열려도 **지금 레벨 식은 그대로** (영향 없음 확인 후 필요하면 하드 재조정)
- 기존 Lv40 만렙 유저의 세이브: 경험치 0에서 41레벨을 향해 다시 오름 (손해 없음 · 여분의 경험치는 이미 0으로 버려지는 구조), 스위치 끄면 원래대로 (되돌릴 수 있게 `p.level` 은 건드리지 않음)
