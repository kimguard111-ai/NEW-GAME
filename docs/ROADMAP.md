# 로드맵 — 재미 키우기 · 시스템 완성도 (v1.9 ~ v1.15)

기준 버전 v1.8.1. 아트는 사용량 제한이 풀릴 때마다 아무 패치 사이에 끼워 넣습니다 (`art_raw/` 업로드 → 바로 적용).

## 지금 상태 진단
| 영역 | 있는 것 | 비어 있는 것 |
|---|---|---|
| 전투 | 9종 무기, 구르기, 예고 패턴, 타격 정지, 콤보 경험치 | 근접은 한 방 휘두르기뿐 (v1.8.1에서 느려져 단조로움) · 무기별 손맛 차이가 수치뿐 |
| 성장 | 능력치 4종(선형) · 스킬 4종 · 강화 +10 | **빌드 선택지가 없음** — 누구나 같은 캐릭터가 됨 |
| 장비 | 등급 · 추가 옵션 · 전설 효과 6종(무기만) | 방어구·헬멧 전설 없음 · 세트 없음 · "이걸 노리고 간다"는 목표 장비가 없음 |
| 출격 | 뒤지기 · 시체 가방 · 탈출 · 결과 화면 | **매 판이 비슷함** — 맵 안 돌발 상황·선택이 없음 |
| 거점 | NPC · 상점 · 창고 · 정비소 | **쌓아 올리는 것이 없음** — 크레딧·고철을 쓸 곳이 부족 |
| 소모품 | 구급상자 · 탄약 | 투척물·버프 아이템 없음 (수류탄은 스킬로만) |
| 엔드게임 | 위협 1~5 · 오늘의 의뢰 · 타이탄 부활 | Lv30 이후 목표가 얇음 |
| 편의 | 세이브 코드 · 설정 · 도움말 | 인벤토리 정렬·잠금 · 장비 비교 · 도감/업적 · 첫 플레이 안내 |

## 순서를 정한 기준
1. **매 판 체감되는 것부터** — 전투 → 출격 변수 → 빌드. 새 맵·새 적은 지금 루프가 깊어진 다음.
2. **루프를 닫는 것** — 주운 것이 어디로 가는지(거점 성장)가 있어야 드랍 쾌감이 오래감.
3. 패치마다 밸런스 봇으로 측정 · 회귀 테스트 · 기존 세이브 이전 보장 (기능 삭제 없음).

## 패치 계획
### v1.9 — 근접 손맛 · 무기 개성
- 근접 **3타 콤보**: 1·2타 빠르게, 3타 강타(범위·경직·넉백 ↑). 느려진 공속을 리듬으로 보완
- 근접 **차지 공격**(길게 누르기): 회전 베기 / 내려찍기 — 무리 처리용
- 총기별 손맛: 저격 관통 연출, 산탄 근거리 넉백, LMG 연사할수록 탄 퍼짐 감소(예열), 권총 빠른 무기 교체
- 처치 연출 차등: 치명타 처치 · 폭발 처치 · 근접 마무리 시 각각 다른 효과/소리

### v1.10 — 출격 돌발 상황 (매 판 다르게)
- 맵마다 출격 시 0~2개 **무작위 사건**: 보급 투하(먼저 가면 독차지, 적 몰려옴) · 생존자 구조(호위 → 보상) · 잠긴 금고(열쇠/해킹) · 변이 둥지(파괴 시 보상, 방치 시 적 증가) · 떠돌이 상인
- **조건부 탈출**: 기본 탈출 외에 "발전기 켜기" · "크레딧 지불" · "보스 처치 후 열림" 탈출 — 빨리 나갈지 더 뒤질지 선택
- 출격 중 **긴장 곡선**: 오래 머물수록 적 증원 경보(3단계) — 욕심과 탈출 사이 고민

### v1.11 — 빌드: 특성 · 스킬 갈래
- 5레벨마다 **특성 3개 중 1개 선택** (총 6개, 정비공에게서 초기화) — 예: "구르기 후 1초 피해 +30%", "탄창 마지막 3발 치명타", "근접 처치 시 체력 회복"
- 스킬 4종마다 **강화 갈래 2개** (수류탄 → 집속탄 / 소이탄 등)
- 능력치는 그대로 두고, 특성이 능력치 방향과 시너지 나게 설계

### v1.12 — 장비 목표: 전설 확장 · 세트
- 전설 효과 6 → 14종: **방어구·헬멧 전설** 추가 (구르기 잔상, 피격 시 보호막 등)
- 지역 **세트 장비** 4종 (2/3세트 효과) — 특정 맵·보스에서만 나옴 → "이걸 노리고 출격"
- 보스별 **고유 이름 장비**(낮은 확률) · 드랍 시 전용 연출

### v1.13 — 거점(캠프) 성장
- 캠프 시설 업그레이드 (크레딧 + 고철 + 전자 부품 소모): 의무실(출격 시 구급상자 지급) · 사격장(무기 숙련) · 창고 확장 · 작업대 단계(제작 가능 목록 확장) · 무전실(사건 정보 미리 보기)
- 시설이 보이게 캠프 맵에 실제로 지어짐 → 성장 체감
- 크레딧·재료가 남아도는 후반 경제를 여기서 흡수

### v1.14 — 소모품 · 투척물
- 퀵슬롯 소모품: 화염병 · 섬광탄 · 지뢰 · 전투 자극제 · 방탄판(즉시 방어 보충)
- 뒤지기·제작(작업대)으로 획득 → 뒤지기 보상이 다양해짐

### v1.15 — 엔드게임 · 편의 완성
- 위협 6~10 **변형 규칙**(적 강화 + 보상 배율, 매주 바뀌는 규칙 조합) · 주간 도전
- 도감(적·장비) · 업적 · 기록(최대 콤보, 최장 생존 등)
- 인벤토리 정렬·잠금·장비 비교 · 일괄 분해 필터 · 첫 플레이 안내
